# ATALAYA — Copiloto de trading

Herramienta personal de análisis y apoyo a decisiones de trading (cripto Binance + acciones EE. UU.).

- **App**: `index.html` (todo en un solo archivo). Publicada con GitHub Pages.
- Los datos de mercado vienen de APIs públicas (Binance, Twelve Data, Finnhub) directamente desde tu navegador.
- Las API keys se guardan SOLO en el navegador de cada dispositivo (localStorage); nunca en este repositorio.
- La ejecución en Binance Testnet requiere el puente local (`puente_atalaya.py`, no incluido aquí) corriendo en el Mac.

⚠️ Uso personal. No es asesoría financiera. Ninguna herramienta garantiza resultados.
